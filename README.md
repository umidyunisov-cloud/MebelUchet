# Учёт мебели — Android v1

## Самый простой способ получить APK

1. Создайте аккаунт на GitHub.
2. Создайте новый репозиторий.
3. Загрузите содержимое этого проекта в репозиторий.
4. Откройте **Actions**.
5. Выберите **Build Android APK** → **Run workflow**.
6. Дождитесь окончания сборки.
7. Откройте выполненный workflow → **Artifacts**.
8. Скачайте `MebelUchet-debug-apk`, распакуйте ZIP и установите `app-debug.apk` на телефон.

Android Studio не нужна.

## Что считает приложение

Остаток клиента = Сумма заказа − Заклад

Общие расходы = Распил + Запчасти + Расходы + Мастер

Доход = Сумма заказа − Общие расходы
